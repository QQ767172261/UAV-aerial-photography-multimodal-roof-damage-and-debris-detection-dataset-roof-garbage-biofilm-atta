## 数据集摘要
本数据集为红外+可见光多模态屋顶巡检数据集，合计13820张图像，图像分辨率1536×2048，红外与可见光图像未做像素对齐。包含屋顶垃圾、生物膜附着、杂草、瓦片破损移位、屋面板裂缝、天沟氧化凹陷等10类屋顶病害与杂物目标，同时提供YOLO、VOC、COCO三套标注，划分训练/验证/测试集，适合研究多模态融合屋顶缺陷检测、航拍屋顶巡检AI模型。

## 应用场景
- 建筑屋顶无人机巡检、屋面病害自动化排查
- 屋顶老化、渗漏隐患前置识别
- 可见光+红外多模态目标检测算法研究
- 房屋安全评估、老旧建筑运维数字化

## 应用价值
1. 覆盖屋面杂物、植被、瓦片损伤、裂缝、天沟锈蚀等多种典型屋顶病害，类别丰富，贴合建筑运维真实需求；
2. 红外+可见光双模态数据，可用于多模态融合检测、对比实验，标注齐全，无需自行转换；
3. 明确划分训练、验证、测试子集，可直接用于模型训练、对比评测；
4. 标注包含大量小目标、低对比度缺陷，对复杂屋面背景下缺陷检测算法鲁棒性训练有较高价值；
5. 标注同时提供三种主流格式，适配YOLO、MMDetection等绝大多数检测框架。
